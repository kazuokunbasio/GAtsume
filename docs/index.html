GAtsume

ゴキあつめ — 奇妙な小さな住人を集める放置型コレクションゲーム

このアプリについて

GAtsume は、部屋にエサや家具を置いてさまざまな「ゴキ」が訪れるのを観察・収集する、 SwiftUI 製の放置型コレクションゲームです。

ブラックユーモアと奇妙な可愛らしさを併せ持った、毎日眺めたくなる小さな住人たちを集めましょう。

よくある質問

  • 広告を消したい: 設定タブの「広告を削除」から課金で永久に非表示にできます。
  • 機種変更時: 設定 → 「購入を復元」をタップしてください。
  • データを消したい: 設定 → 「すべてリセット」で端末内のデータが削除されます。
